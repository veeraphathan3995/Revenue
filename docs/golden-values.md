## D4. กรณีทดสอบบังคับ (15 ข้อ)
1. นักศึกษา ภาค 2 + ภาค 1 = 0 → ยอดสุทธิ 0 ไม่เกิด error หารศูนย์
2. รุ่นแรกเข้า (`cohort = be_year mod 100`) → คิดค่าลงทะเบียน 1,000 ต่อหัวเฉพาะภาค 1 รุ่นอื่นไม่คิด
3. ระดับปริญญาโทใช้ตารางหัก 1,000/1,000/200 รวม 5,000 และคืนค่าห้องสมุด 60% ของ 1,000
4. แถว `gen_ed_out` ติดลบ รวมเข้ายอดได้ และไม่ถูก validation ปฏิเสธ
5. บริการวิชาการที่ปิด `apply_mgmt_deduction` ไม่หัก 40%
6. ค่าเช่าที่เดือนสิ้นสุดก่อนเดือนเริ่ม → จำนวนเดือน 0 พร้อมคำเตือน
7. Overhead ที่เว้นอัตราว่าง → ใช้อัตราตั้งต้น; ใส่อัตราเฉพาะโครงการ → ใช้อัตรานั้น
8. สัดส่วนรายเดือนภาคใดไม่ครบ 100% → บล็อกการบันทึก
9. ตารางจัดสรรคอลัมน์ใดไม่ครบ 100% → บล็อกการส่งอนุมัติ
10. เปลี่ยนปีงบ: เดือน ต.ค.–ธ.ค. ได้ พ.ศ. = ปีงบ − 1
11. รายรับจริงที่วันที่ไม่ตรงเดือนปีงบที่เลือก → แสดงคำเตือน
12. เงินเหลือจ่ายรายเดือนเมื่อยังไม่กรอกรายจ่าย → แสดงคำเตือนและยอดคงเหลือ = ยกมา + รับสุทธิสะสม
13. เทียบรับจริงถึงเดือน ธ.ค. กับ ก.ย. ได้ประมาณการสะสมต่างกันถูกต้อง และ % เป็นค่าว่างเมื่อประมาณการสะสมเป็น 0
14. เวอร์ชัน `approved`/`locked` แก้ไม่ได้ทุกช่องทาง (UI, API, SQL ตรงด้วย role ผู้ใช้)
15. นำเข้าไฟล์ที่มีแถวผิดหนึ่งแถว → ไม่บันทึกอะไรเลย
